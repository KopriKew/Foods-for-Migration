# Foods for Migration / Musofirlar Ovqatlari
* **⚠️ Muammo:** Ko‘p migrantlar mustaqil ovqat tayyorlashni bilishmaydi yoki mablag‘ sarflashadi, va fast food lar yoki yarim tayyor ovqat sotib olishadi va baribir qazon ovqatlariga yetmaydi)
* **✅ Yechim:** 100, 150, 300 rubl miqdoridagi arzon mahsulotlardan (masalan, tuxum, piyoz va h.k.) keshbek kartalaridan foydalanib, unumli va mazali taomlar tayyorlash retseptlari, matnli va video qo'llanmalar.

Musofirlikda yurgan yurtdoshlarimiz uchun hamyonbop, tez va oson tayyorlanadigan taomlar bo‘yicha qo‘llanma va video-blog platformasi.
